# Route table
| Prompt | Workflow |
| --- | --- |
| Explain, explore, ambiguous idea | discovery |
| Non-trivial implementation | feature |
| Failure or unknown root cause | bug |
| Tests, coverage, QA | test |
| Diff or PR review | review |
| Auth, vulnerability, secrets | security |
| Schema, backfill, upgrade | migration |
| Browser, hydration, accessibility | ui-verification |
| Localized low-risk edit | trivial-change |

Overlap priority: security, migration, bug, review, test, feature, UI verification, discovery, trivial change.
